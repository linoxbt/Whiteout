# Whiteout brand

The mark is a peak whose summit dissolves into white (a whiteout). The edge of its
snow cap is a **W**, and the relic, a sealed tile turned on its corner, sits inside
the mountain: the whole game in one glyph.

| File | Use |
| --- | --- |
| `mark.svg` | Primary mark on light backgrounds |
| `mark-on-dark.svg` | On navy or photography |
| `app-icon.svg` | Favicon and app icon (navy tile) |
| `logo-sheet.png` | Overview: mark, lockup, inverse, icon sizes |

Wordmark: Saira, weight 750, width 125%, tracking 0.16em, uppercase.

| Colour | Hex |
| --- | --- |
| Ink (rock) | `#102233` |
| Glacier | `#2f7fb5` |
| Snow shade | `#b4cde1` |
| Relic amber | `#e3a82f` |

Keep clear space of one relic width around the mark. Don't outline, rotate or recolour the relic.
